## Описание

REST API для системы управления посылками пользователей. 
Сервис позволяет регистрировать посылки, получать список своих посылок и просматривать информацию о конкретной посылке. 
Пользователь определяется по анонимной сессии и имеет доступ только к собственным посылкам. 
Стоимость доставки рассчитывается автоматически раз в n минут на основе веса посылки, стоимости содержимого и актуального 
курса доллара.

## Архитектура

В приложении используется несколько слоев: API, Service и Repository.

- **API** — обрабатывает HTTP-запросы, маршрутизацию и передаёт данные в сервисный слой.
- **Service** — содержит бизнес-логику приложения и координирует работу с данными.
- **Repository** — инкапсулирует работу с базой данных через SQLAlchemy.

Основное направление зависимостей:

```text
API -> Service -> Repository -> PostgreSQL
```

Redis используется для кеширования курса валют и как брокер сообщений для Celery. 
Периодический расчёт стоимости доставки выполняется Celery worker'ом по расписанию Celery Beat.

## Быстрый старт

Создайте файл `.env` на основе `.env-example` и заполните необходимые параметры окружения:

Запустите приложение:

```bash
docker compose up --build
```

Docker Compose запустит API и необходимые сервисы: PostgreSQL, Redis, Celery worker и Celery Beat.

После запуска Swagger UI доступен по адресу:

```text
http://localhost:8000/docs
```

## Переменные окружения

Основные группы настроек:

- `DB_*` — параметры подключения к PostgreSQL.
- `REDIS_*` — параметры подключения к Redis и номера БД для broker/cache.
- `USD_RATE_TTL` — время кеширования курса USD.
- `CELERY_TASK_INTERVAL` — интервал периодического расчёта стоимости доставки.
- `CBR_URL` — URL API для получения курса валют.
- `DEBUG` — режим отладки и логирования.

## API

- `GET /health` — проверка состояния приложения.
- `GET /api/v1/parcels` — получение списка посылок пользователя.
- `POST /api/v1/parcels` — создание новой посылки.
- `GET /api/v1/parcels/{parcel_id}` — получение информации о посылке по id.
- `GET /api/v1/parcel-types` — получение списка типов посылок.
- `POST /api/v1/calculate_delivery_prices` — постановка задачи на расчёт стоимости доставки.

Полная документация API доступна в Swagger по адресу `/docs`.

## Тесты

Перед запуском тестов должна существовать тестовая база данных `test_delivery` и также должен быть запущен контейнер с postgres. 
Миграции Alembic применяются автоматически тестовой инфраструктурой.

Запуск тестов:

```bash
uv run python -m pytest -v
```

Полная проверка качества проекта:

```bash
make check
```

`make check` запускает линтинг, проверку форматирования, mypy, pytest и bandit.

CI настроен через GitHub Actions и выполняет полный quality gate на push в ветку `dev`.
