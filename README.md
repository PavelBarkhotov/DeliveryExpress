Routes:
- зарегистрировать посылку
- Получить все типы посылок и id типов
- Получить список своих посылок со всеми полями
- Получить данные о посылке по ее id

Про посылки:
Посылки бывают трех типов - одежда, электроника, разное.
Информация о посылке должна содержать - Название, вес, тип, стоимость в долларах, стоимость доставки
